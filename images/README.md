# Project Figures

Place approved original figures in this directory, for example:

- `soc-architecture.png` — final architecture diagram used in the paper.
- `cpu-schematic.png` — CPU module schematic.
- `soc-top-schematic.png` — SoC top-level schematic.
- `dma-schematic.png` — DMA controller schematic.
- `xcelium-waveform.png` — high-resolution functional simulation waveform.
- `rtl-to-physical-flow.png` — actual flow diagram, clearly distinguishing synthesis from full physical implementation.
- `routed-layout.png` — final Innovus layout screenshot.

Use the actual outputs from the project. Do not label a recreated or illustrative image as an original Cadence result. Confirm that paper, collaborator, institution, and tool-output sharing is permitted before making figures public.
